# Language Quick Reference

## Statements

define, assignment, if, else, while, for, in, func, return, break, continue, import, and from-import.

## Values

null, number, bool, string, array, object, function, native function, and iterator.

## Operators

+ - * / % - ! == != < <= > >= && ||

## Access

value[index], value.member, and function calls.

## Iteration

Arrays yield values, strings yield characters, and objects yield keys.
