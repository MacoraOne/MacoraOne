Bytecode runtime

Compile to bytecode.
Execute on a VM.

greenServeFE (greenServe Fast Execution) is a C-based execution engine for the greenServe language. It parses .gsve source, compiles it into bytecode and executes that bytecode in an explicit virtual machine. Runtime modules can be loaded from native shared libraries.

Execution model

From source to bytecode

The frontend keeps the greenServe lexer/parser language model, while execution moves from recursive AST evaluation to a bytecode compiler and VM.

1. Source

Programs are written in .gsve files.

2. Frontend

The lexer and parser build the program representation.

3. Compiler

The compiler produces instructions, constants, names and child function code objects.

4. Virtual machine

Frames track instruction pointers, operand stack bases and lexical environments.

5. Native modules

Runtime-loadable .so modules extend the engine through its native module layer.

6. CLI

Run source directly, inspect bytecode, or trace execution from the command line.

.gsve source
   → lexer
   → parser / AST
   → bytecode compiler
   → GSCode instructions
   → virtual machine
   → output
Build and run

Run a program

Build the engine from the build repository using its existing C11 Makefile.

git clone https://github.com/dominexmacedon-docs/greenServeFE-build.git
cd greenServeFE-build
make clean all
./greenServeFE test.gsve
./greenServeFE --dump test.gsve
./greenServeFE --trace test.gsve

The published runtime repository contains Linux x86_64 release packages. Follow its README for the current engine and module installation instructions.

Example program

Variables, iteration, functions and objects

This example is based on the included test.gsve program in the build repository.

define total = 0;
for (n in [1, 2, 3, 4]) {
    total = total + n;
}

func add(a, b) {
    return a + b;
}

define result = add(total, 5);
show("total:", total);
show("result:", result);
show("array:", [1, 2, result]);
show("object:", {name: "greenServe", version: 1});

if (result >= 15 && total == 10) {
    show("vm ok");
} else {
    show("vm failed");
}

Run the sample:

./greenServeFE test.gsve

The example uses the implementation's documented define, for, func, show, array and object syntax.

Runtime features

What the VM supports

Language values

Numbers, strings, booleans, null, arrays and objects.

Control flow

Conditions, while loops, for/in iteration, break and continue.

Functions

Function calls, recursion and captured lexical environments.

Expressions

Arithmetic, comparisons, logical operators, assignment, indexing and member access.

Built-ins

print, show, len, str, num and type.

Inspection

Bytecode disassembly via --dump and execution tracing via --trace.

The build README notes that the full Node.js HTTP/server bridge from the earlier greenSERVE runtime has not yet been ported to the new VM native ABI. Treat network/server functionality as separate integration work rather than an already completed VM feature.
