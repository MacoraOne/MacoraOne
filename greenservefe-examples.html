Executable .gsve examples for values, arrays, objects, functions, closures, native imports, and the VM server interface.

Closures

The VM supports captured lexical environments and closures.

func make_adder(base) {
    func add(value) {
        return base + value;
    }
    return add;
}

define add10 = make_adder(10);
print(add10(5));
print(add10(20));

Native module import

Requires the native gsnum shared library to be installed and discoverable.

import gsnum;
print(gsnum.sum(1, 2, 3, 4));
print(gsnum.mean([10, 20, 30]));
print(gsnum.sqrt(144));

Server handler

Demonstrates the current VM server module interface.

import server;

func home(req, res) {
    res.send("Hello from greenServeFE");
}

server.get("/", home);
server.serve(".", 8080, {
    index: "index.html",
    static: true
});

HTTP API response

Explore the VM server interface and API-oriented route patterns. Networking support depends on the runtime build.

import server;

func health(req, res) {
    res.send("greenServeFE 1.0.3 is running");
}

server.get("/health", health);

Run examples

make clean all
./greenServeFE docs/examples/01-hello.gsve
./greenServeFE --dump docs/examples/03-arithmetic.gsve
./greenServeFE --trace docs/examples/15-functions.gsve

For native imports, install the matching module and ensure GREENSERVE_MODULE_PATH points to its shared-library directory. External HTTP/database/crypto dependencies and network access may be required for those module examples.
