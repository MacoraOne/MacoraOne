MACORAONE / DEVELOPER DOCUMENTATION

one Commands

Complete documented command reference for MacoraOne's one CLI: package discovery, versioned installs, Android project creation, push and build workflows.

Help and version

one --version
one --help

Install / remove ecosystem

one install
one uninstall

Manage the full ~/.macoraone installation and components.

List packages

one list
one list-available

Query installed packages and discover published Linux x86_64 release assets.

Install a package

one install gsnum
one install gsnum@1.0.0
one install gsnum 1.0.0
one install greenServeFE@1.0.2
one install gs_db@1.0.0
one install gs_crypto@1.0.0
one install gs_http@1.0.0
one install gs_form@1.0.0
one install gs_log@1.0.0

Package names and versions are discovered from published release assets, not hard-coded into the CLI.

Uninstall one package

one uninstall gsnum
one uninstall greenServeFE
one uninstall gs_db

Create Android app

one create WeatherApp

Select Java or Kotlin when prompted.

Push app changes

one push WeatherApp WeatherApp
one push WeatherApp dominexmacedon-docs/WeatherApp

Build app

one build WeatherApp

Dispatches the selected GitHub Actions workflow and reports the artifact URL.

Build and install the CLI from source

make clean all
make test
sudo make install
sudo make uninstall

Typical dependencies: GCC/Clang C11 compiler, make, git, GitHub CLI (for project workflows), curl, jq, unzip, and sudo for system-level install operations. Package installation requires network access to the release catalogue.
