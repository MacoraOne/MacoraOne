About

About Dominex Macedon

Dominex Macedon is the creator and developer behind the MacoraOne project ecosystem. The work spans programming-language development, server-side programming, Android development, runtime systems, virtual machines, command-line software, developer tooling, and programming-related data resources.

The MacoraOne ecosystem brings these independent projects together while allowing each repository to remain focused on its own technology and purpose.
